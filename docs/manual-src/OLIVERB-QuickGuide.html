The modules

  • Valve — triode preamp: Drive, Bias (even harmonics), Sag (tube compression), Tone (transformer), Mix. At Output moves it to the end of the chain; Echo Amp puts it inside the tape machine.
  • Filter · Big Dial — 11-step, 18 dB/oct passive high-pass + Impedance, Magnetism, Character, Dynamics, Artefacts, Gain.
  • Echo · Two Track — Time, Feedback, Input, Output, Hiss, Mix, Wear. Sync swaps Time for a note division.
  • Mod · LFO / Envelope — Rate, LFO Depth, Env Depth, Sens, Speed: both steer the big dial ±3 octaves.
  • Spring Tank — Spring (amount), Tension (decay), Drive (crash).
  • Master — meters, chain readout, Output.

Install

macOS: run OLIVERB-macOS.pkg (right-click → Open the first time). Windows: run OLIVERB-Windows-Setup.exe (SmartScreen: More info → Run anyway). Linux: copy OLIVERB.vst3 to ~/.vst3/. Then rescan plug-ins — it's under Deestech. Installs over v1 and v2.0; 2.1.0 changes only the faceplate.

Signal flow

Valve first (default) colours everything after it; At Output makes it a master tube stage after the spring. Filter Pre: repeats inherit the dial — sweeps drag the tail. Post: the filter carves the finished signal, tails included. The Master chain readout always shows the current order.

First sound in 60 seconds

  1. Insert on a drum loop; load preset Waterhouse Rockers.
  2. Turn valve Drive up, watch the 12AX7 glow: thicker, compressed, not louder.
  3. Sweep the big Frequency dial — hear the corner peak and the clacks.
  4. Push Feedback past 80 %; the repeats build toward self-oscillation.
  5. Tap Dub Send to Held — the input stops, the loop keeps circling. Dub-out. Tap it back.
The numbers that matter Valve drive up to +36 dB, level-compensated; zero drive ≈ 1 % 2nd harmonic. Feedback unity = 80 % (beyond it the machine self-oscillates, safely). Echo time 20–2000 ms, tape-style pitch bend on changes. Mod range ±3 octaves around the dial. Output is hard-limited — it cannot run away.

The six moves

Tube gluePreset Valve Warmth. Drive 30–50 %, Bias 60 %, Sag 20 %: weight without obvious distortion. Sag up for bloom; At Output to round off the tails.
Dub throwFeedback + Mix high. Un-mute one hit, tap Dub Send to Held, let it circle and decay.
Ride the dialFilter Pre, sweep Frequency mid-tail — every repeat bends with you. Add Artefacts for the clack.
Pitch-bend echoAutomate Time: small moves warble, big jumps dive-bomb.
SirenFeedback past unity, no input. Tune with Time, filter with the dial, crash the spring.
Auto-wahEnv Depth positive, step 4–6, Impedance up. Negative depth ducks instead — an ungate.

Resize (14)

Drag the corner: 60–150 % of 980 × 930, sharp at any size.

If something's wrong

Not in the DAWRescan; check the VST3 folder; macOS: clear quarantine (manual §2).
Thicker than v1That's the valve at its default 35 %. Switch it off for the v1 sound.
Tail never diesFeedback ≥ 80 % — that's the instrument. Pull it down.
Too loudOpen Impedance + hot feedback adds real level: trim filter Gain or Output.
